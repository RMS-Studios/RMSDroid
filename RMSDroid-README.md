# RMSDroid

RMSDroid is the official Android client for [RMS](https://github.com/zxkuhl/RMS), a Discord client modification built by RMS STUDIOS.

## Download

Grab the latest APK from the [Releases](https://github.com/zxkuhl/RMSDroid/releases) page.

## Features

- Full RMS mod support on Android
- Plugins, themes, and customization
- Persistent login and settings
- Desktop-style Discord UI on mobile
- Built by zxkuhl under RMS STUDIOS

## Installation

1. Download the latest `.apk` from [Releases](https://github.com/zxkuhl/RMSDroid/releases)
2. Enable "Install from unknown sources" in your Android settings
3. Open the APK and install
4. Log in and enjoy RMS on Android

## Open Source

RMSDroid is currently closed source. Open sourcing it is being considered for the future — stay tuned!
